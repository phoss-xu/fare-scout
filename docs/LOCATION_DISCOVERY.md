# 地点发现与停留晚数

更新：2026-11-01。

## 交互

所有出发地和目的地控件删除国家/城市/机场类型下拉框。输入名称或代码后始终搜索全部类型；
结果保留类型和代码，帮助区分“上海城市范围”和“上海虹桥机场”，不要求用户先理解数据分类。

搜特价的“任何地方”可直接点击打开分类浏览，也会取消不限目的地勾选。
搜特价、创建监控以及出发地更换共用 `location_browser.js`，提供全球热门、内地热门、港澳台、欧洲、免签、
北美、南美、东亚、东南亚、大洋洲、中东和非洲。
热门是人工精选的浏览起点，不是实时热度排名；区域提供城市推荐与国家/地区入口，不构成互斥的地域划分。
浏览列表不是全部可搜索地点，全球目录仍可通过输入搜索。

分类只用于浏览，不过滤输入搜索。在“欧洲”中输入香港国际机场，仍能搜到 HKG。
多选可跨分类保留，并支持再次点击取消；确认只关闭面板，选择仍是表单草稿。
搜特价每次最多 6 个地点范围，监控最多 100 个，后端原有查询批次限制不变。

## 停留范围

`nights.js / nights.css` 使用两个原生 range 输入叠放在同一轨道。
左右手柄分别调整最少/最多晚数，范围为 1–30，实时显示范围，禁止交叉，允许相同晚数。
支持触摸/鼠标拖动、点击轨道选最近手柄，以及键盘箭头；重合时根据拖动方向分开手柄。
仍以 `min_nights` / `max_nights` 提交，不改变上游接口或后端晚数含义。

## 地点分类数据

`app/location_groups.py` 保存编辑精选 ID，并从 `locations.py` 获取规范地点记录。
分类接口复用受登录保护的 `/api/locations?groups=1` 与 `?group=...`；普通 `?q=` 搜索不接受前端的浏览分类约束。
地点选择值仍是带类型的规范 ID，没有根据用户输入自行猜测国家或城市意图。

## 免签口径

用户尚未回复护照偏好时，先采用“中国大陆普通护照短期旅行互免签证精选”，页面明确展示适用护照、核查日期和来源。
当前展示 16 个互免普通护照目的地作为浏览起点，不声称覆盖全部互免或单方面免签政策。

依据：[中国领事服务网《中外互免签证协定一览表》](https://cs.mfa.gov.cn/zggmcgx/cgqzapecswlxk/ylb/202607/t20260716_11984014.html)，
官方表更新至 2026-05-29，本次核查日期 2026-11-01。
只纳入表中明确适用普通护照的精选项；未将仅适用于外交/公务护照的国家、团体旅游或落地签混入。
例如日本、法国、美国不因中国单方面便利其他国家旅客入境就反向判为中国普通护照免签；厄瓜多尔被表内注明暂需事先签证，因此未纳入。

选择分类不构成针对具体旅客、行程或未来出行日的入境资格认定。停留期限、目的、材料和中转要求需在出行前向官方核实。
此分类没有自动更新机制，也不自动按用户账号推定国籍或护照；切换其他护照口径需补充对应官方资料。
