## 维护与验证

`app/static/destination-photos.json` 是照片元数据入口。`airports` 只列有依据的同城客运机场；不根据名称相近或国家相同自动借用照片。`city_code`、`country_code`、`city_name` 取自地点目录，用于范围监控的图例及国家归属；审计要求与城市记录一致。国家图例不将城市照片当作整个国家的封面。`id` 指向同一组 CSS 构图规则，`position` 记录审阅后的焦点；修改时同步 `destination-photos.css`。未收录地点保留原报价和机场占位。恢复脚本对 Unsplash 按目录记录的宽度下载，对 Commons 使用来源页核实的固定 download_url，不自行改写图片尺寸；两者均核对完整宽高，避免恢复为与已审阅原图不同的版本。

恢复缺失图片（不覆盖已有文件）：

```bash
python3 scripts/update_destination_photos.py
python3 scripts/update_destination_photos.py BKK TPE
# 明确需要恢复同一张原图时才使用 --force
```

离线核对真实文件尺寸、机场别名冲突、CSS 焦点一致性与覆盖缺口：

```bash
python3 scripts/audit_destination_photos.py
node --test tests/test_offer_photos.mjs tests/test_route_map.mjs
python3 -m unittest discover -s tests -p test_destination_photos.py
```
