# 外观设置

2026-11-02：按 THEME_RESEARCH.md 的六套原创 RGB 草案实现，不标为 Pantone 官方配方。

入口为页头「外观设置」，桌面 390px 右侧栏，手机全宽；内容滚动，标题与恢复默认保持可见。
六张主题卡展示真实底色、文字与强调色，选中带勾。点击立即生效，不改古书字体或摄影。
颜色由 themes.css 的语义变量管理，日期票券、展开面板、原生输入框与按钮跟随主题。

风景更新支持：
- 每小时（默认）：打开时更换，并在整点更新。
- 每天：同一北京时间日期保持同一处，零点更新。
- 每次进入：重新打开或刷新时更换，停留时保持静态。
- 固定当前：跨刷新保留当前照片。

切换频率不立即切图。恢复默认返回「旧书纸 + 每小时 + 65% 顶部底色」。本地存储失败时本次预览仍生效，明确提示不能保存。
Escape、关闭按钮或桌面遮罩可关闭，关闭后恢复入口焦点；使用原生 dialog 管理键盘焦点。
偏好范围为当前浏览器/站点，不做账号同步。

验证：23 项前端与 7 项 HTTP 回归通过；30 组实际 CSS 文字/底色对比度达到 4.5:1。
实际浏览器检查桌面、390px 与 320px，操作主题、频率、重载、重置、日期与目的地展开。
这不是整站 WCAG 认证；每日边界由模拟时钟验证，没有等待完整一天，也没有执行真实航班查询或邮件通知。

## 手动风景与顶部滚动（2026-11-02，按最新反馈收回顶部）

侧栏提供六张实拍缩略图，含 Henry Lai 的香港维港夜景。原图与许可记录在
app/static/assets/places/CREDITS.md，运行时无需第三方图片请求。
选图后切到「固定当前」，由 rotation.select 保存当前照片；更改更新频率可继续自动轮换。
页面通过 landscapechange / landscapeselect 事件同步缩略图与图鉴，不复用航班目的地状态。

「顶部底色不透明度」控制顶部风景上方的主题底色遮罩，0% 通透、100% 实底。
照片本身不变淡。下方表单、报价和结果继续使用实底，不受滑杆影响。
偏好为 surfaceOpacity（0–100 的整数，默认 65）；上一轮误加的 opacity 不再使用，
旧偏好回退到新的默认值。恢复默认返回旧书纸、65% 顶部底色、每小时换景与滚动开关开启。

world-backdrop.js / world-backdrop.css 仅在 atlas-scene 内渲染。维港照片的远处楼群、
中央塔楼与前景高楼使用 CSS 遮罩分层；两座塔楼从远景中排除后独立绘制，以免重复。
天空采用配合照片的颜色渐变，水面为原摄影。这是摄影的分层视觉构图，不是实时城市景象。

只响应原生滚动，以不同幅度向上移动；位置有上限，手机幅度减半，不绑定鼠标、不循环播放。
提供 motion 开关并遵循 prefers-reduced-motion；其他风景保持静态。所有图层受顶部区域裁切，
不会覆盖或移动下方填写信息的区域。

遮罩变化及表单背景色保持不变，检查桌面与手机布局、日期展开、选图和刷新保存。
