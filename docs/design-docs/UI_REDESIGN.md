# Fare Scout 界面改版

日期：2026-11-01。用户要求参考 [AI Design Skills](https://github.com/elayadesign/ai-design-skills) 优化已有界面。
已阅读并应用 [landing-page-design](https://github.com/elayadesign/ai-design-skills/blob/main/skills/landing-page-design/SKILL.md)
及其推荐的 [redesign-existing-projects](https://github.com/elayadesign/redesign-skill/blob/main/skills/redesign-existing-projects/SKILL.md)。
本次按已有产品工具界面处理，保留 Python 标准库服务与原生前端，不改成营销落地页。

## 观察到的问题

- 大宣传区与工作台标题重复，查询入口在窄屏被推到下方。
- 搜特价表单不断垂直追加条件，假期七个按钮和长说明默认占满一段屏幕。
- 细字、全大写英文、Georgia 数字与系统中文混用，视觉层级分散。
- 每个结果默认展开完整往返航班与行李，跨目的地比较要长距离滚动。
- 初始搜索结果区是空白，查询中主要依赖一行文本，界面缺少完整状态。

## 设计选择

- 绿色品牌色，统一中性色表面、边框和弱底色，不加促销色或背景渐变。
- Manrope 400/500/600/700 本地字体；中文使用平台字形回退。价格与时间使用等宽数字，不再另配衬线字体。
- style.css 集中定义 Heading / Title / Body / Caption / Button 命名样式，以及技能给定的字号、间距和圆角尺度。
- 页头缩为品牌和账号，页签直接切换工作区；默认进入搜特价。独立导航模块 ui.js 提供方向键、Home/End 和焦点状态。
- 搜索主区先显示出发地、目的地和日期范围，次行保留停留晚数与主按钮；人数/预算/星期/中转及假期按需展开。
- 手机展开面板参与正常文档布局，避免大弹层覆盖结果；默认搜索按钮在 390×844 首屏可见。
- 假期折叠后，已选名称和“调休待公布”继续显示在入口上。日期手改后清除选中状态。
- 结果卡片先呈现目的地、总价、日期与去返程摘要，完整机场、航段、行李信息展开查看；核价与加入监控仍保留。
- 初始/成功空结果/错误都有明确视图，查询中显示卡片骨架；支持减少动态效果偏好，悬停、按下和键盘焦点状态统一。
- 不添加虚构价格、历史低价、照片评价或使用人数；所有报价仍来自真实查询。

## 文件与资产

- index.html：页面结构、搜索布局、折叠分组、语义导航、跳转内容链接和 favicon。
- style.css / deals.css / locations.css / holidays.css / auth.css / automation.css / flights.css：对应组件样式。
- ui.js：页面切换、键盘导航、展开筛选摘要、失效输入展开定位。
- deal_views.js：摘要结果卡片、详情折叠和各类结果状态；deals.js 连接交互状态。
- holidays.js：入口显示选中假期与参考状态；日期与假期数据保持原口径。
- server.py：显式映射新增 UI 模块、本地字体和图标，无任意路径暴露。
- assets/：Google Fonts 的 Manrope 字体及 OFL；Phosphor 官方 airplane-tilt 图标及 MIT 许可。没有新增包依赖。

## 验证边界

11 项现有前端相关测试通过，覆盖报价元数据转义、核价链接、日期排序、航班与行李展示和假期日期回填；修改模块完成语法检查。
实际页面检查 1280×900 桌面、390×844 手机，检查主操作可见、展开筛选、地点搜索、假期回填、原有监控与创建表单。
另以真实 Kiwi 搜索验收结果卡片、详情、日期筛选和转监控草稿；不保存验收监控、不向用户发通知。
本次视觉交付仍需用户实际体验确认；不因测试通过就视为用户满意，未提交或部署。

### 出发地入口补充

搜特价的当前出发地改为可点击的大按钮，显示名称、类型和代码，旁边明确标“更换”；展开后仍使用全球地点搜索。
这是 locations.picker 的可选展示方式，未改变监控表单和目的地多选。

### 2026-11-02 · Departure Club

新增 `departure.css` 作为现有组件样式之后的品牌视觉层。暖纸色背景、墨黑文字、航行蓝主色和荧光黄行动色；首页采用编辑式大字与抽象航线海报，搜索表单采用登机牌结构。海报由 HTML/CSS 排印与轨道线组成，无外部图片依赖。移动端海报缩至 200px，筛选展开保留原有单列行为，支持减少动态效果偏好。

### 2026-11-02 · 旧书印刷字体

品牌名与首页海报英文采用本地 IM Fell English Regular 400，海报调整为小写 `go / further.`，呈现参考图的旧活字质感。中文、表单和价格继续使用原有字体栈。字体来自 Google Fonts 的 `ofl/imfellenglish/IMFeENrm28P.ttf`，许可保存在 `app/static/assets/IM-Fell-English-OFL.txt`；通过显式静态路由提供，首页预加载并使用 `font-display: swap`。


## 2026-11-02 搜索颜色分区

`app/static/search-panels.css` 在 `departure.css` 后加载，集中管理搜索区的响应式呈现：蓝色总框架、白色地点卡片、浅黄日期卡片、浅紫停留卡片、黄色主操作，以及独立白色结果区域。颜色配合标题、边界和间距表达区域职责。桌面并列，手机纵向排列；展开筛选在手机内联显示。保留往返、经济舱与 HKD 的实际功能范围。


## 2026-11-02 渐进式搜索修订

同日后续修订使用动态山海风景和按需展开的搜索，替代上节的全量彩色分区表单。设计、代码路径、生成素材及验收边界见 [LIVING_SEARCH.md](LIVING_SEARCH.md)。


## 2026-11-02 实拍图鉴修订

首屏改用真实摄影、无边框融合与前后层视差，英文地名沿用 IM Fell English，中文名与介绍使用宋体衬线，详情与来源见 [TRAVEL_ATLAS.md](TRAVEL_ATLAS.md)。渐进式搜索继续保留。


## 2026-11-02 静态风景修订

用户要求取消裸眼 3D；已移除分层、视差和持续动态。真实原图静态展示，移除手动分类/翻页，改为重新打开/刷新以及每到整点自动换景，详见 [TRAVEL_ATLAS.md](TRAVEL_ATLAS.md)。

## 2026-11-02 登录页与中文字体统一

登录页改用工作区相同的纸色、墨绿文字、真实风景渐隐和柔和卡片。取消旧大蓝色宣传海报及硬边表单，蓝色仅用于主操作；图片沿用已授权的岚山竹林，并保留作者和许可入口。
英文展示文案使用现有 IM Fell English，中文标题、表单、工作区地名/描述与外观设置统一使用思源黑体本地子集，拉丁正文继续使用 Manrope。
字体由 Adobe 官方 Source Han Sans CN VF 制作，按 OFL 保留名称要求改名为 Fare Scout Sans；覆盖现有文案和常用汉字，子集外字符使用系统字体。
来源、许可、体积与重建方法见 [CHINESE-FONT.md](../../app/static/assets/CHINESE-FONT.md)。

`auth.css` 改为组件样式末尾加载，统一覆盖历史视觉层；`auth.js` 同步登录/注册/初始化标题和说明，保留密码版与 Passkey 两种登录方式。
桌面左右布局、手机上下布局，手机将照片缩为介绍区，保留首屏主操作。错误提示在表单内显示，注册切换不离开当前页。


## 2026-11-02 风景首屏与出行机会

根据用户提供的太空旅行参考，搜特价采用「下一次，换个地方醒来」大标题、深色真实风景与跨在下沿的明亮搜索条。`getaway.css` 最后加载，限定 `#deals-panel`；登录页、其他工作台、六套配色和现有风景偏好继续沿用各自组件。图库照片保留作者与许可；图注只呈现地点，不追加用途解释。

结果第一项在桌面跨列呈现，价格与停留安排优先；每日推荐只展示服务端已有的可玩白天、请假及日历估算信息，普通搜索仅用目的地当地日期差展示停留晚数。目的地导航由本次实际返回的报价生成，与已返回日期过滤联动；按钮中的价格仅代表所选日期内返回的较低价。所有核价链接和「帮我继续留意」监控草稿入口保留，草稿默认暂停自动查价。

手机收起时并排展示出发与目的地，日期独立一行；编辑地点时纵向展开。390px/320px 实际浏览器验证无横向溢出，详细验收和真实查询边界见 PROGRESS.md 本轮记录。


## 2026-11-02 中文改回思源宋体

以用户最新偏好为准，全局中文改用本地思源宋体子集，覆盖标题、正文、表单和按钮。此前黑体说明为历史记录；当前字体来源、OFL 许可与重建方式见 [CHINESE-FONT.md](../../app/static/assets/CHINESE-FONT.md)。


## 2026-11-02 文案精简

界面只保留操作入口、当前状态及影响选择的信息。空状态不重复讲解操作步骤，设置不复述控件作用，卡片不重复展示相同行李说明。按钮直接使用「登录」「创建监控」等动作；计算口径放在可展开说明中，报价范围、日期口径、核价与必要验证信息保持可见。
