# Fare Scout 界面改版

日期：2026-11-01。用户要求参考 [AI Design Skills](https://github.com/elayadesign/ai-design-skills) 优化已有界面。
已阅读并应用 [landing-page-design](https://github.com/elayadesign/ai-design-skills/blob/main/skills/landing-page-design/SKILL.md)
及其推荐的 [redesign-existing-projects](https://github.com/elayadesign/redesign-skill/blob/main/skills/redesign-existing-projects/SKILL.md)。
本次按已有产品工具界面处理，保留 Python 标准库服务与原生前端，不改成营销落地页。

## 观察到的问题

- 大宣传区与工作台标题重复，查询入口在窄屏被推到下方。
- 搜特价表单不断垂直追加条件，假期七个按钮和长说明默认占满一段屏幕。
- 细字、全大写英文、Georgia 数字与系统中文混用，视觉层级分散。
- 每个结果默认展开完整往返航班与行李，跨目的地比较要长距离滚动。
- 初始搜索结果区是空白，查询中主要依赖一行文本，界面缺少完整状态。

## 设计选择

- 绿色品牌色，统一中性色表面、边框和弱底色，不加促销色或背景渐变。
- Manrope 400/500/600/700 本地字体；中文使用平台字形回退。价格与时间使用等宽数字，不再另配衬线字体。
- style.css 集中定义 Heading / Title / Body / Caption / Button 命名样式，以及技能给定的字号、间距和圆角尺度。
- 页头缩为品牌和账号，页签直接切换工作区；默认进入搜特价。独立导航模块 ui.js 提供方向键、Home/End 和焦点状态。
- 搜索主区先显示出发地、目的地和日期范围，次行保留停留晚数与主按钮；人数/预算/星期/中转及假期按需展开。
- 手机展开面板参与正常文档布局，避免大弹层覆盖结果；默认搜索按钮在 390×844 首屏可见。
- 假期折叠后，已选名称和“调休待公布”继续显示在入口上。日期手改后清除选中状态。
- 结果卡片先呈现目的地、总价、日期与去返程摘要，完整机场、航段、行李信息展开查看；核价与加入监控仍保留。
- 初始/成功空结果/错误都有明确视图，查询中显示卡片骨架；支持减少动态效果偏好，悬停、按下和键盘焦点状态统一。
- 不添加虚构价格、历史低价、照片评价或使用人数；所有报价仍来自真实查询。

## 文件与资产

- index.html：页面结构、搜索布局、折叠分组、语义导航、跳转内容链接和 favicon。
- style.css / deals.css / locations.css / holidays.css / auth.css / automation.css / flights.css：对应组件样式。
- ui.js：页面切换、键盘导航、展开筛选摘要、失效输入展开定位。
- deal_views.js：摘要结果卡片、详情折叠和各类结果状态；deals.js 连接交互状态。
- holidays.js：入口显示选中假期与参考状态；日期与假期数据保持原口径。
- server.py：显式映射新增 UI 模块、本地字体和图标，无任意路径暴露。
- assets/：Google Fonts 的 Manrope 字体及 OFL；Phosphor 官方 airplane-tilt 图标及 MIT 许可。没有新增包依赖。

## 验证边界

11 项现有前端相关测试通过，覆盖报价元数据转义、核价链接、日期排序、航班与行李展示和假期日期回填；修改模块完成语法检查。
实际页面检查 1280×900 桌面、390×844 手机，检查主操作可见、展开筛选、地点搜索、假期回填、原有监控与创建表单。
另以真实 Kiwi 搜索验收结果卡片、详情、日期筛选和转监控草稿；不保存验收监控、不向用户发通知。
本次视觉交付仍需用户实际体验确认；不因测试通过就视为用户满意，未提交或部署。

### 出发地入口补充

搜特价的当前出发地改为可点击的大按钮，显示名称、类型和代码，旁边明确标“更换”；展开后仍使用全球地点搜索。
这是 locations.picker 的可选展示方式，未改变监控表单和目的地多选。
