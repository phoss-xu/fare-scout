# 真实风景旅行图鉴

## 当前版本：静态实拍与自动换景

2026-11-02，用户体验后要求取消立体效果；当前版本不再使用前景分层、透视、鼠标视差、持续运动或生成式补底。只展示项目已核对来源的真实摄影。

- 保留自然/城市五处风景、IM Fell English 英文地名、宋体中文名及一句短介绍，摄影作者与原图链接同步更新。
- 自然/城市不是手动筛选器。每次重新打开或刷新会在五处之间换景，顺序交错自然与城市；页面停留到下一整点再更换一处，从后台回来若跨小时则只更新一次。
- 同一小时内普通可见性变化不换图；搜索日期和目的地条件不会受风景更新影响。
- 页面没有分层视差、图片动画或倾斜；当前图片样式 transform 和 animation 均为 none。
- `landscape.js` 管理静态照片、文本与加载失败提示；`landscape-rotation.js` 管理访问/整点更新，localStorage 只保存公开风景 ID；`landscape.css` 管理静态排版。图片均同源加载，不请求外部摄影服务。

素材及许可见 [CREDITS.md](../../app/static/assets/places/CREDITS.md)。旧缩略图保留，当前页面不再使用；本轮立体实验资源已清理，先前生成图 coast-dawn.jpg 也未用于当前首屏。
