# 每日机票推荐

实现于 Workers + D1；保留的 Python 服务继续提供原有监控，隐藏每日推荐入口。
新能力尚未部署。已有 Cron 每分钟触发；沿用原来的邮件 HTTPS 适配器和账号收件邮箱。
平台调度约定参见 [Cloudflare Cron Triggers 官方文档](https://developers.cloudflare.com/workers/configuration/cron-triggers/)，
UTC 触发与用户选择的北京时间由业务层转换。

## 设置与推荐口径

「搜特价 → 发现目的地」同时承接每日发现和本次搜索，复用同一套机票卡片及加入监控流程。
推送时间和请假偏好通过结果区的「修改偏好」弹窗设置，不再新增独立页签和设置页。
出发机场、人数和预算会带入未编辑的搜索表单；已经编辑的搜索条件不会被刷新覆盖。

推荐偏好可设置北京时间 HH:mm、香港 HKG / 深圳 SZX、总预算（0 不限）、成人数、
最多请假 0–2 天、至少 1–5 个完整白天，以及凌晨往返优先。默认建议为北京时间 08:30、两机场、
1 成人、不请假、可玩 2 个白天、凌晨往返优先；新账号须在页面保存并开启。
与现有降价提醒独立，无需先创建航线监控。

每天查询未来 84 天内的最多 6 个时间窗口，每个选中机场一次：优先最近 4 个可休息的周末，
另 2 个位置轮询较远周末和假期，始终纳入展望期内最近假期。优先凌晨往返时，
最近周末的查询直接向上游传递凌晨出发和凌晨返抵约束，其余窗口保留灵活时段。
目的地不限，结果排除中国内地、香港、澳门。仅经济舱、HKD 总价、每程最多 8 小时、1 次中转。
每城市保留一条代表行程，先少请假、再凌晨偏好、再价格、再可玩天数，最多展示 6 个目的地。
这属于本次有限结果中的较低价，不是历史最低，也没有完整市场覆盖。

请假采用中国内地日历，与使用香港还是深圳机场无关。正式年份包含调休补班；
工作日 18:00 后起飞、06:00 前返抵当天不计假，其余占用工作日按整天计。
未计机场交通、跨境通关与休息；用户需自行预留。以目的地当地时间计算可玩白天：
09:00 前到达、20:00 后离开才算完整一天。周六 01:40 出发、05:40 到达，周日 20:20 回程、
周一 00:10 返抵的组合可玩两整天、无需请假；周一白天返抵则计一天假。

日历复用 `app/static/holidays.json`。2027 年仍为参考窗口，未知补班不补造；
涉及参考年份的行程持续标注预计请假天数和待核实状态。更新日历须同时更新来源与状态。

## 队列与投递

- `daily_preferences` 保存账号偏好及下一次北京时间对应的 UTC 时刻。
- `daily_editions` 保存每日简报、运行关联、失败数、报价快照和邮件租约；账号 + 当地日期唯一。
- 提前约 30 分钟生成持久化 `search_runs` / `search_tasks`，与手动搜特价并行存在，
  复用原有查询租约、重试和重启恢复；单轮最多 12 次范围查询。
- 全失败、成功无匹配、部分失败分别展示；成功无匹配不表示市场无航班。
- 到设定时间且查价完成才投递；查询繁忙或重试可能延后。漏过的历史日期跳过，不补发多天简报。
- 邮件使用稳定的简报 ID 作为幂等键，失败最多尝试 5 次；超过计划时间 24 小时跳过。
- 修改推送时间会调整同日未投递简报的计划；若新时间落在次日，取消旧日待发简报。
  其他出行偏好从下一份生成的简报生效，已有简报保留自己的查询口径。
- 关闭每日推荐取消未发送邮件；已经发出的网络请求无法撤回。邮件服务未启用时先保存网页简报。

API：GET/POST `/api/daily`，另由 GET `/api/state` 返回本人 `daily` 状态；沿用会话和 CSRF。
读写不接受客户端声明账号归属。每日结果不会写入监控采样或触发降价提醒。

## 本地验收

`npm run db:local && npm run dev`，打开 `http://localhost:8787`。
Wrangler 本地不会自行周期触发 Cron；可请求 `http://localhost:8787/__scheduled` 接续到期任务。
开发验收保持 `MAIL_ENABLED=false`。部署前须将 `0006_daily.sql` 应用于目标 D1，
再发布代码；本次不进行远程迁移或部署。

必要检查：`npm run test:workers`、`npm run test:frontend`、`npm run build`（dry run）。
每日业务测试使用临时 D1 和模拟 Kiwi/邮件；与真实数据源验收分别记录于 PROGRESS.md。
