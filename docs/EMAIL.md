# 邮件提醒配置与验收

自动查价和网页提醒不依赖邮件配置。收件邮箱可在网页「提醒中心」修改，分别保存在当前用户账号下。
发信凭据从项目根目录 `.env` 或进程环境变量读取；环境变量优先。`.env` 已忽略，不应提交。
`.env.example` 提供字段说明，不包含真实凭据。

## 配置

填写本地 `.env` 中的 `FARE_SMTP_HOST`、`FARE_SMTP_PORT`、`FARE_SMTP_SECURITY`、
`FARE_SMTP_USER` 和 `FARE_SMTP_PASSWORD`。`FARE_SMTP_FROM` 为空时使用用户名作为发件地址。
新用户默认使用自己的登录邮箱收件；修改收件地址只影响当前用户。
`FARE_SCOUT_EMAIL_TO` 仅保留旧单人版内部兼容，不会作为新账号的公共默认地址。
当前支持密码/授权码认证的 SMTP，使用 SSL 或 STARTTLS，不接受不加密的连接。

以 Gmail 为例：`smtp.gmail.com`，SSL 端口 `465`，或 STARTTLS 端口 `587`。
Google 官方说明见 [SMTP 文档](https://developers.google.com/workspace/gmail/imap/imap-smtp)。
如使用 Gmail 应用专用密码，需要账号支持该功能并开启两步验证，某些账号策略可能不提供。
参阅 [应用专用密码说明](https://support.google.com/mail/answer/185833)。
也可使用其他服务的 SMTP 授权码，无需使用收件邮箱作为发件邮箱。

修改后重启 `python3 -m app.server`，网页会显示配置是否完整。
「邮件服务已就绪」只表示本地配置完整，不代表已经通过 SMTP 认证或完成投递。
目前未实际向用户邮箱发送验收邮件，真实认证、投递和收件箱/垃圾邮件归类仍待验证。

## 提醒与发送规则

- 比较同一监控、目的地、往返日期、人数、舱位与币种的上次有效报价。
- 默认下降至少 HK$100，或首次进入总预算时生成一条提醒。
- 首次采样只建立基线；若已在预算内，则生成「进入预算」提醒。
- 同价或高于该组合已提醒最低价的报价不重复提醒。
- 报价、提醒、邮件队列在同一事务中保存；读取提醒不影响邮件发送状态。
- 缺配置时保留网页提醒，邮件等待配置；配置完整后尝试发送未过期的队列记录。
- 邮件失败最多尝试 5 次，间隔依次为 2、4、8、16 分钟，第 5 次失败后停止。
- 超过 24 小时、出行日期已过或该监控提醒已关闭时跳过邮件。
- SMTP 的「已发送」表示服务器接受提交，不代表用户已在收件箱收到。
- 进程在 SMTP 接受邮件后、写回状态前中断，重启后可能重复发送；稳定 Message-ID
  可供邮件系统识别，但不承诺端到端只投递一次。

## 定向测试

`python3 -m unittest discover -s tests -v` 使用临时数据库和模拟 SMTP，不发送真实通知。
`tests/test_mail.py` 覆盖 SSL/STARTTLS、收件人、邮件内容、缺配置、发送状态及重试。
