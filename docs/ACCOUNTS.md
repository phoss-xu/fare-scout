# 账号与数据隔离

## 当前能力

- 邮箱与密码注册、登录、退出；用户保存昵称、登录邮箱与独立收件邮箱。
- 监控、设置、价格记录与提醒均通过 `watches.owner_id` 归属用户。
- 未登录不能读取或修改业务数据；越权访问监控统一返回 404。
- 自动采样在用户退出后继续运行；后台邮件按监控所有者读取收件地址。
- 发信服务是管理员配置，不要求每个用户提供 SMTP 凭据，也不向用户返回凭据。

## 旧数据迁移

迁移前使用 SQLite backup 保留旧数据库副本。`FARE_OWNER_EMAIL` 指定旧记录所属账号；
服务在开放 HTTP 请求前创建预留账号，把原监控归到该账号，保留原采样和提醒。
预留账号没有初始密码，普通注册不能领取该邮箱下的数据；其他注册账号从空白开始。

服务在终端输出 `/setup#token=...` 初始化入口，只供本机操作者使用，有效期两小时。
用户自行设置密码，令牌随后失效；后台调度在预留账号激活后继续执行。
令牌只保存摘要，放在 URL 片段中以避免进入 HTTP 请求日志；页面读取后移除片段。
重启会保留未过期的初始化令牌；过期后为尚未激活的账号生成新入口。
已设置密码的账号不会重置密码或重新发令牌。
不要通过公共 API 暴露初始化令牌。

本机操作者可使用 `python3 -m app.accounts set-password <邮箱>` 按用户要求设置或更新密码。
密码从隐藏输入读取，不放入命令参数；操作会撤销该账号所有旧会话和初始化令牌。

## 密码与会话

- 密码 6–128 个字符（由用户选择调整），支持中文与空格；随机盐和 PBKDF2-HMAC-SHA256 600,000 次迭代。
- 数据库不保存明文密码，也不保存明文会话令牌。
- 256 位随机会话使用 HttpOnly、SameSite=Lax Cookie，绝对有效期七天，退出后撤销。
- 修改请求要求当前会话的 CSRF 令牌，同时检查 Origin、请求格式和 Host。
- 登录及注册按账号和来源地址计数限流，窗口 15 分钟。
- 持久化账号信息的 SQLite 文件与本地 `.env` 使用仅当前用户可读写的权限。
- 参数参考 [OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
  与 [会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 本地验证与部署边界

当前服务仍仅监听本机，已完成本地账号隔离，不等于已部署给远程用户。
对外部署前应使用成熟的应用服务器/反向代理与 HTTPS，设置 Secure Cookie，
并按实际部署域名调整 Host/Origin 校验；当前 HTTP 处理器只允许本机 Host。
尚未实现邮箱验证、自助找回密码、多因素认证与账号删除。
未验证的登录邮箱不能作为已经证明的邮箱所有权；不应将当前注册流程直接公开上线。

必要测试包括两个账号的读取/写入隔离、逐用户邮件收件人、会话撤销与过期、CSRF、
同源限制以及旧数据保留。测试账号、测试数据库和模拟邮件均与用户账号隔离。
