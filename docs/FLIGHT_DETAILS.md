# 报价详情与数据边界

## 当前显示

- 去程/返程：当地日期与起降时间、机场代码与全名、总时长、直飞或中转次数。
- 航段详情：航空公司、航班号、起降机场、城市和国家、舱位、单航段飞行时长。
- 中转：同一机场的当地时间间隔；更换机场时明确提示交通与转机时间需核对。
- 行李：报价源返回的随身小包、手提、托运行李件数，缺失字段与 0 件分别展示。
- 不通过异地当地钟表时间相减计算飞行时长，优先使用数据源的 durationSeconds。

## 已核对的数据源

2026-11-01 直接读取 Kiwi 官方 MCP `tools/list`：当前只提供 `search-flight` 和反馈工具，
没有单独的行李额度或航班详情查询接口。

`search-flight` 的行程字段包含 `baggage`、`outbound`、`inbound`，每程有 `segments`。
行李仅定义 personalItem、cabinBag、checkedBag 整数件数，未提供公斤数和尺寸。
工具描述称行李是所有旅客的总量，输出 schema 描述却称按旅客计，两处说明不一致。
页面因此展示原始已返回件数，不自行标为“每人”或“合计”，提示核对每人、每程适用额度。
航站楼、退改签和座位条件未返回，页面明确标注，不根据航司常见规则补填。

原始报价 JSON 已完整保存在 observations.offer，已有样本无需重新查价即可显示详情。
渲染模块 `static/flights.js` 与样式 `static/flights.css` 独立；通用文本转义在 `static/format.js`。
报价内容通过文本转义输出，预订链接继续只接受 HTTPS。

## 验证

`node --test tests/test_flights.mjs` 覆盖跨时区时长、缺失与零件行李、机场/航班元数据、
内容转义、跨日中转与更换机场。浏览器须检查实际报价的桌面和手机视图，以及展开详情。
