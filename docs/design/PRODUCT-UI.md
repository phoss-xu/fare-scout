# 产品共用视觉规则

以当前风景登录页为基准：留白、细线图标、圆形玻璃操作、轻边框、低幅度动效。

- `app/static/product-ui.css` 是登录、工作台、分享页、管理页的共用控件入口。主页面再加载 `scenic-workspace.css`，负责延续登录页的全屏风景、标题留白与悬浮搜索构图。功能样式保留查询和结果布局职责。
- 首屏风景贯穿页面，以景色和大标题形成视觉重心；搜索以透明表面和分隔线组织，避免重复套卡片。开始搜索后压缩风景区域，让报价回到实色阅读表面；行程与提醒页保留同源风景页头。风景图与名称、归属和操作共用 `landscape.js` 的当前选择。
- 圆形图标操作至少 44px，线宽 1.6；文字按钮和输入框圆角 16px，小型选项 12px。文字操作保留可见标签，图标操作保留辅助标签。
- 风景上使用 `--scenery-*`，阅读区使用全局主题语义色；浮层可轻微模糊，正文卡片采用实色、细边框。地图控件沿用主题，底图保留地理颜色。
- `--ui-*` 定义视觉尺寸、表面、阴影及动效；交互 200ms，内容和浮层进入 300ms，复用 `--curve`。减少动态偏好停用移动动画；减少透明偏好改用实色。
- 字体只由 `style.css :root --family` 及其全局字体选项决定。货币继续读取 preferences/currency，不在视觉层处理金额或修改报价快照。
- 新增控件优先复用 `.primary`、`.small-btn`、`.icon-btn`、`.trip-tool` 及 `ui-icons.js`。避免在功能样式中重新引入独立的按钮材质、字体、硬编码操作颜色或弹跳动画。

验收应覆盖登录方式切换、搜索日期/地点展开、设置、监控表单，以及有数据时的卡片/列表/地图和航线详情；桌面与 390px 小屏分别检查。
