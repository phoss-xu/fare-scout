本次用最终适配器查询 2026-11-20 出发、11-23 返程，HKD、1 成人、经济舱，未写入用户报价库、未发送通知：

- 伦敦（LON）→ 东京（TYO）：8 条通过范围校验的行程，含 LHR/LGW → NRT/HND，最低返回价 HK$7,668。
- 此前直接探测 GB → JP 也返回有效航班；尚未逐国、逐城市验证接口覆盖。
- 上游使用裸地点代码；曾试验把本地类型前缀发给上游，出现错误地点，因此类型前缀只用于本地保存，不能直接传给 Kiwi。
- 即使输入具体机场，上游也可能返回附近机场；适配器必须核对实际四个机场是否属于所选国家、城市或精确机场。
- 不同实际机场或实际往返日期的报价分别记录和比较，不能混作同一行程的降价。

这些结果只证明上述请求在当时成功，不保证之后库存、报价或目录覆盖。报价仍需在预订页核验。

## 下一步验证方法

取得候选服务凭据后，在独立验收库选取相同机场、实际往返日期、人数、经济舱、币种做小样本并行查询，
分别记录源、查询时刻、总价、机场、行李与预订入口。只有价格口径和时效可比，才考虑跨源比较与提醒。
未验证的部分包括商业许可、实际配额与费用、全地区覆盖、真实邮件投递及预订成交价。
